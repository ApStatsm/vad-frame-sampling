# ver3 결과 보존

[결과 해석](../../../evaluation_ver3.md) · [방법](../../../method_ver3.md)

이 폴더는 사용자 실행 완료 ver3의 CSV·sweep·분석 요약을 그대로 복사한 GitHub 열람용 근거다. 원본 폴더는 `outputs/analyses/xd_context_ver3_full_20261116_022711/`이며 날짜는 KST다.

[sources.json](sources.json)에 원본 경로와 사본 SHA-256을 기록했다. sweep의 개별 run summary 경로·해시는 서버 원본을 가리킨다. 원본 NPZ·feature·개별 run summary는 이 폴더에 포함하지 않는다. 기존 분석을 재실행하지 않았다.
